# Hi, I'm Michael Fowler

I'm an operations research analyst in defense cost estimating, with three years of life-cycle cost estimates, earned value and schedule analysis for Navy aviation acquisition programs. I build open-source tools for that work, made for the way it actually gets done: in Excel, by a team, with numbers someone has to defend.

**[cost-core](https://github.com/MichaelFowler1/cost-risk-toolkit)** runs a cost shop's monthly analysis straight from Excel: cost risk and the P80, EVM forecasts from a spreadsheet or an IPMDAR delivery, DCMA 14-point schedule checks, JCL, learning curves, AoAs and portfolio choice. Every run writes a `report.xlsx` and a `brief.pptx`, and nothing leaves your machine. Try `pip install cost-core`, then `ce-core demo cost-risk`.

**[xlgit](https://github.com/MichaelFowler1/excel-git)** is git diff and merge for Excel. Two people edit the same workbook on their own branches, and git merges it cell by cell while keeping charts, tables, pivot tables and macros. Try `pip install xlgit`, then `xlgit demo`.

Outside my own projects, I've had [a bug fix merged into SciPy](https://github.com/scipy/scipy/pulls?q=is%3Apr+author%3AMichaelFowler1+is%3Amerged) (float32 accuracy in `mannwhitneyu`) and [tests merged into pandas](https://github.com/pandas-dev/pandas/pulls?q=is%3Apr+author%3AMichaelFowler1+is%3Amerged).
